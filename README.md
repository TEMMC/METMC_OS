# METMC OS v6

METMC OS v6 is an Android desktop environment designed to integrate
Android applications and Linux applications into one PC-style interface.

## Architecture

Android
  -> METMC Desktop
  -> Window Manager
  -> Linux Bridge
  -> Debian Linux runtime
  -> Linux Display Bridge
  -> Android Surface

## Shared storage

/data/media/0/METMC_OS

## Linux rootfs

/data/local/linux/rootfs
